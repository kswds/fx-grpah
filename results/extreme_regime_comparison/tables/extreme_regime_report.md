# Extreme Regime Model Comparison Tables

Source tables:

- `seed_metrics_aggregate.csv`
- `seed_extreme_metrics_aggregate.csv`

Sorting rule:

- Each scenario table is sorted by `hit_ratio_mean` descending, then `rmse_mean` ascending.

Metrics:

- `Hit`: average sign hit ratio
- `Extreme Hit`: sign hit ratio on the largest target-move subset within that scenario
- `RMSE`, `MAE`: regression error
- `Pairwise Hit`: cross-sectional ranking hit ratio
- `IC`: Spearman information coefficient
- `LS Sharpe`: long-short portfolio Sharpe from the model ranking
